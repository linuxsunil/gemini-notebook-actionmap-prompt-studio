# ActionMap Prompt Studio

**Same SOP. Same AI (Gemini Notebook). Two completely different learning experiences.**

A zero-server, client-side web app and live side-by-side demo showing how **Action Mapping** transforms AI-generated HTML from passive "click-and-read" study guides into performance-first workplace simulations.

## Why This Exists

AI tools like **Gemini Notebook** can now generate standalone interactive HTML pages from any policy or SOP in minutes. That solves the *authoring speed* problem—but not the *learning design* problem.

When given a standard prompt, AI defaults to passive e-learning patterns: upfront content dumps, flip cards, and recall quizzes with `"Correct / Incorrect"` feedback.

**ActionMap Prompt Studio** proves that the difference isn't the tool—it's the instructional design architecture behind the prompt.

## What’s Inside

### 1. Side-by-Side Live Proof
Compare two real HTML files generated by Gemini Notebook from the **exact same 1-page source document** (`SOP-SEC-04: Phishing & Data Privacy Response`):

| Feature | Passive Study Page (Standard Prompt) | Action-Mapped Simulation (ActionMap Prompt) |
| :--- | :--- | :--- |
| **Opening** | Policy summary & KPI blocks | Drops learner straight into an urgent fake CEO email |
| **Interactivity** | Flip cards & click-to-reveal Do/Don't panels | Inspectable mail headers, link/attachment traps, Slack triage |
| **Feedback** | `"Correct"` / `"Incorrect"` recall grading | Realistic workplace consequence timelines (`T+01 min`, `T+06 min`) |
| **Policy Reference** | Memorized upfront | Collapsible **SOP Quick-Reference** drawer used only on demand |
| **Debrief** | Percentage quiz score | Habit-based **Incident Readiness Summary** & audit trail |

### 2. Action-Mapped Prompt Architect
A built-in prompt builder that replaces generic parameters (*"topic, age group, colors"*) with Cathy Moore’s **Action Mapping** inputs:
* **Measurable Business Goal**
* **Observable On-the-Job Action**
* **Realistic Mistakes & Workplace Barriers**
* **Simulation Format** (Inbox/Slack triage, branching threads, or diagnostic dashboard)

Includes 3 one-click presets (**InfoSec**, **Client Escalation**, **Manager Feedback**) and a one-click **Copy Prompt** button ready to paste into Gemini Notebook.

---

## How to Use

1. Open the **[Live App](#)** (no login, no backend, no API keys required).
2. Explore **Tab 1 (Side-by-Side Live Proof)** using the Split / Passive-Only / Action-Mapped-Only toggle.
3. Switch to **Tab 2 (Prompt Architect)**, load a preset or enter your own performance problem, and click **Copy Prompt**.
4. Upload your own SOP/policy into **Gemini Notebook**, paste the prompt into chat, and export the generated interactive site as HTML.
